caseUNC is a Luau testing framework used to score script executor function support, behavioral correctness, and anti-spoof integrity. Results are HMAC-SHA256 sealed and can be inspected here on GitHub Pages. 

loadstring(game:HttpGet("https://raw.githubusercontent.com/caseclosed-mp4/caseUNC/main/build/caseUNC.luau"))()

Run in executor

  1. Inject your executor and join a simple baseplate with a character.
  2. Execute the loadstring above (or the GitHub raw build URL).
  3. caseUNC prints to both the external terminal (rconsole) and Roblox output.
  4. Report JSON is sealed, saved (if filesystem works), and copied to clipboard when possible.
  5. Paste the base64 report code below to visualize passes, fails, and spoof risk.

Optional config

getgenv().caseUNCConfig = {
    useExternal = true,
    useRoblox = true,
    hidePasses = false,
    shuffleTests = true,
    delay = 0,
}

What caseUNC checks

UNC surface

Cache, closures, console, crypt, debug, filesystem, input, instances, metatable, misc, scripts, drawing, websocket.

Behavioral tests

Functions must behave correctly, not merely exist. Known vectors catch shallow stubs.

Anti-spoof

Closure identity, hook restore, env isolation, crypt vectors, debug shape, and integrity canaries.

Crypto seal

Reports carry HMAC-SHA256 envelopes over canonical material so tampering is visible in the viewer.
